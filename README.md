Question :1️⃣ What is the difference between var, let, and const?
Ans:>
#The let --- used to declare a variable that is block-scoped and can be reassigned a new value later.
#The const ---used to declare a constant reference to a value and it can't
be reassigned a new value later.
#Var ---used to declare a variable.
